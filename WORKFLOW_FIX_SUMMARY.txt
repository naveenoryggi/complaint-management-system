ROOT CAUSE ANALYSIS
--------------------------------------------------------------------------------

PRIMARY BUG: Complaints created without StatusMasterId set

Location: CreateComplaintCommandHandler.cs

When a complaint is created:
  - "status" display name is set to "Submitted" ✅
  - "statusId" (StatusMasterId) is left as NULL ❌

This causes workflow transitions to fail because:
  1. WorkflowEngine gets currentStatusId = Guid.Empty (from NULL)
  2. Tries to find transition: Guid.Empty → target status
  3. No such transition exists
  4. Validation fails
  5. Status never gets updated
