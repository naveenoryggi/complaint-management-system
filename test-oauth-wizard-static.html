About Modern Email Authentication

Important: Most email providers (Gmail, Outlook, Office 365) have disabled basic password authentication for security reasons.

You must use OAuth 2.0 - a secure, modern authentication method where you authorize this application through your email provider's official login page.

No passwords stored in database
Automatic token refresh
Required for Office 365 & Gmail
Revoke access anytime

Setup Instructions

Follow these steps to configure OAuth in Azure Active Directory

📋 Azure AD Configuration Steps:
  1. Go to portal.azure.com
  2. Navigate to "Azure Active Directory" → "App registrations"
  3. Click "+ New registration"
  4. Enter name: Complaint Management Email
  5. Copy the Application (client) ID
  6. Copy the Directory (tenant) ID
  7. Create a Client Secret and copy it
  8. Add API Permissions: IMAP.AccessAsUser.All, SMTP.Send
Callback URL:
http://localhost:5000/api/oauth/callback
