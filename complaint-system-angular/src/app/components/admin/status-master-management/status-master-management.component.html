Understanding Status Masters

Status masters define the lifecycle states of complaints in your system:

  • System Statuses: Built-in statuses (e.g., "Open", "In Progress", "Closed") that cannot be edited or deleted
  • Custom Statuses: Company-specific statuses that you can create and customize

Configuration: Each status can have a unique color code, icon, and display order. Use the isFinal flag to mark statuses that represent completed complaints.
