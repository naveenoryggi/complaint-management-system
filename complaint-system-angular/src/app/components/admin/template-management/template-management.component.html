About Communication Templates

Templates define the content of automated notifications sent when events occur in the system. Use placeholders like {{ '{' }}complaintNumber{{ '}' }}, {{ '{' }}title{{ '}' }}, {{ '{' }}assignedToName{{ '}' }} to dynamically insert data.

  • Email Templates: Support subject, plain text body, and HTML body
  • SMS/WhatsApp: Keep messages concise (160-300 characters)
  • System Templates: Pre-configured templates that can be edited but not deleted
