About Notification Rules

Notification Rules determine when and how notifications are sent based on complaint events. Link events to templates and configure recipients, channels, and timing.

  • Priority: Higher priority rules (1-100) are processed first
  • Delay: Set a delay (0-1440 minutes) before sending notifications
  • Send Once: Prevents duplicate notifications for the same event
