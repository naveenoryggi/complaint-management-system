Configure OAuth Application

How to Get OAuth Credentials
Step 1
Go to Azure Portal

Visit portal.azure.com and sign in with your admin account

Step 2
Register New Application
  1. Search for "Azure Active Directory" (or "Microsoft Entra ID")
  2. Click "App registrations" in the left menu
  3. Click "+ New registration"
  4. Enter name: Complaint Management Email
  5. Select "Accounts in this organizational directory only"
  6. For Redirect URI, select "Web" and enter: {{ getOAuthCallbackUrl() }}
  7. Click "Register"
Step 3
Copy Application (Client) ID

On the app Overview page, copy the "Application (client) ID" value

You'll see this on the Overview page
Step 4
Copy Directory (Tenant) ID

Also copy the "Directory (tenant) ID" from the same page

Step 5
Create Client Secret
  1. Click "Certificates & secrets" in the left menu
  2. Click "+ New client secret"
  3. Enter description: "Email Integration"
  4. Set expiration (recommended: 24 months)
  5. Click "Add"
  6. IMPORTANT: Copy the "Value" immediately! It won't be shown again
Step 6
Add API Permissions
  1. Click "API permissions" in the left menu
  2. Click "+ Add a permission"
  3. Select "Office 365 Exchange Online"
  4. Select "Delegated permissions"
  5. Add these permissions:
    • IMAP.AccessAsUser.All (Read emails)
    • SMTP.Send (Send emails)
  6. Click "Add permissions"
  7. Click "Grant admin consent for [Your Organization]"
  8. Confirm by clicking "Yes"
Step 1
Go to Google Cloud Console

Visit console.cloud.google.com and sign in

Step 2
Create New Project
  1. Click the project dropdown at the top
  2. Click "New Project"
  3. Name: "Complaint Management Email"
  4. Click "Create"
Step 3
Enable Gmail API
  1. Go to "APIs & Services" > "Library"
  2. Search for "Gmail API"
  3. Click on it and click "Enable"
Step 4
Create OAuth Credentials
  1. Go to "APIs & Services" > "Credentials"
  2. Click "Create Credentials" > "OAuth client ID"
  3. If prompted, configure OAuth consent screen first
  4. Select "Web application"
  5. Name: "Complaint Management"
  6. Add Authorized redirect URI: {{ getOAuthCallbackUrl() }}
  7. Click "Create"
Step 5
Copy Credentials

Copy the "Client ID" and "Client Secret" that appear

Note: Gmail uses different field names - use Client ID for both fields below, and enter your Gmail address

Copy from "Application (client) ID" in Azure Portal
Copy from "Directory (tenant) ID" in Azure Portal
⚠️ Copy this immediately from Azure - it won't be shown again!
Callback URL for Azure AD: {{ getOAuthCallbackUrl() }} Add this as a redirect URI in your Azure AD app registration
