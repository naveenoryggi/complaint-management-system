About Email Server Settings

Email servers are used to send automated notifications such as complaint updates, assignments, escalations, and status changes to users.

  • SMTP Configuration: Standard email protocol for sending messages
  • Default Server: One server can be marked as default for all notifications
  • Testing: Test your configuration before activating

Step-by-Step OAuth Configuration Guide
1
Go to Azure Portal

Visit portal.azure.com and sign in with your admin account

2
Register New Application
  1. Search for "Azure Active Directory"
  2. Click "App registrations" → "+ New registration"
  3. Enter name: Complaint Management Email
  4. Select "Accounts in this organizational directory only"
  5. Redirect URI (Web): {{ getOAuthCallbackUrl() }}
  6. Click "Register"
3
Copy Application (Client) ID

On the app Overview page, copy the "Application (client) ID" value

4
Copy Directory (Tenant) ID

Also copy the "Directory (tenant) ID" from the same page

5
Create Client Secret
  1. Click "Certificates & secrets" → "+ New client secret"
  2. Enter description: "Email Integration"
  3. Set expiration (recommended: 24 months)
  4. Click "Add"
  5. IMPORTANT: Copy the "Value" immediately! It won't be shown again
6
Add API Permissions
  1. Click "API permissions" → "+ Add a permission"
  2. Select "Office 365 Exchange Online"
  3. Select "Delegated permissions"
  4. Add: SMTP.Send, offline_access
  5. Click "Add permissions"
  6. Click "Grant admin consent" and confirm
1
Go to Google Cloud Console

Visit console.cloud.google.com and sign in

2
Create New Project
  1. Click the project dropdown at the top
  2. Click "New Project"
  3. Name: "Complaint Management Email"
  4. Click "Create"
3
Enable Gmail API
  1. Go to "APIs & Services" > "Library"
  2. Search for "Gmail API"
  3. Click on it and click "Enable"
4
Create OAuth Credentials
  1. Go to "APIs & Services" > "Credentials"
  2. Click "Create Credentials" > "OAuth client ID"
  3. Select "Web application"
  4. Name: "Complaint Management"
  5. Add Authorized redirect URI: {{ getOAuthCallbackUrl() }}
  6. Click "Create"
5
Copy Credentials
