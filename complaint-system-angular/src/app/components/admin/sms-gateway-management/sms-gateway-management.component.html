About SMS Gateway Settings

SMS gateways are used to send automated text message notifications such as complaint updates, urgent escalations, and status changes to users via SMS.

  • Providers: Supports Twilio, AWS SNS, MessageBird, Nexmo, and custom gateways
  • Default Gateway: One gateway can be marked as default for all SMS notifications
  • Testing: Test your configuration before activating
  • Cost Tracking: Monitor SMS costs per message
