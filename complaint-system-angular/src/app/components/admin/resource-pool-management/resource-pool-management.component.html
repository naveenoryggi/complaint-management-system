About Resource Pools

Resource pools are groups of users that can be assigned to handle escalated complaints. Pools can be organized by Branch, Department, Section, or as Custom groups.

When an escalation is assigned to a resource pool, the system can distribute work using different methods: Manual (pool members choose), Round Robin (equal distribution), or Least Busy (based on workload).
