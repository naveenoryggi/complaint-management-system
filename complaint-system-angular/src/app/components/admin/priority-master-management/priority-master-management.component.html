Understanding Priority Masters

Priority masters define the urgency levels and SLA requirements for complaints:

  • Priority Level: Numeric value (1-5) indicating urgency, where higher numbers mean higher priority
  • SLA Times: Define response and resolution timeframes in hours
  • System Priorities: Built-in priorities (e.g., "Low", "High", "Critical") that cannot be edited or deleted
  • Custom Priorities: Company-specific priorities with custom SLA times

Configuration: Each priority can have unique color codes, icons, and display order for visual distinction.
