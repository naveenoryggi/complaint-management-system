Understanding Roles & Permissions

Roles define sets of permissions that can be assigned to users. The system includes:

  • star System Roles: Pre-defined roles (System Admin, Company Admin, etc.) that cannot be deleted
  • star Custom Roles: User-created roles that can be modified or deleted
  • star Escalation Levels: Defines the hierarchy for complaint escalation

lightbulb Tip: Use the "Manage Permissions" button to customize which permissions are granted to each role.
