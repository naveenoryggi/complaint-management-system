Understanding Category Hierarchy

Categories can be organized in a two-level hierarchy:

  • Parent Categories: Top-level categories (e.g., "HR Issues", "IT Support")
  • Child Categories: Subcategories under a parent (e.g., "Salary & Payroll" under "HR Issues")

Benefits: Better organization, improved reporting, simplified complaint routing. To create a subcategory, select a parent when creating/editing a category.
