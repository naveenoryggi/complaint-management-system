================================================================================
  HOW TO PUSH CODE
================================================================================

OPTION 1: Use the Helper Script (Easiest)
------------------------------------------
Simply run:
    powershell -ExecutionPolicy Bypass -File git-push-helper.ps1

Or with custom commit message:
    powershell -ExecutionPolicy Bypass -File git-push-helper.ps1 -CommitMessage "Your message here"

OPTION 2: Manual Git Commands
------------------------------------------
    git add -A
    git commit -m "Your commit message"
    git push

Credentials are automatically used from .git-credentials file.

================================================================================
  TOKEN MANAGEMENT
================================================================================

To update or revoke the token:
1. Go to: https://github.com/settings/tokens
2. Find the token for "Complaint Management System"
3. Regenerate or delete as needed
4. Update .git-credentials file with new token

================================================================================
  TROUBLESHOOTING
================================================================================

If push fails:
1. Check internet connection
2. Verify token hasn't expired (go to GitHub settings)
3. Check if repository exists: https://github.com/naveenoryggi/complaint-management-system
4. Run: git remote -v (should show correct repository URL)

If credentials not working:
1. Check .git-credentials file exists in project root
2. Run: git config --get credential.helper
   Should show: store --file=.git-credentials
