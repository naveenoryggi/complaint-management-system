================================================================================
                          USER INTERACTION FLOW
================================================================================

Step 1: Navigate to Page
  User: Clicks "Email Ticketing Config" in admin menu
  App:  Loads email-ticketing-config component
  API:  Calls GET /api/EmailConfiguration and GET /api/SystemConfiguration
  UI:   Shows action bar with three buttons

Step 2: Click System Settings Button
  User: Clicks the [⚙] System Settings button
  App:  Executes toggleSystemSettings() method
  State: showSystemSettings = true
  UI:   Panel slides down from below action bar

Step 3: Modify Settings
  User: Changes "Token Refresh Interval" from 30 to 45 minutes
  App:  Updates systemConfig.oAuthTokenRefreshIntervalMinutes = 45
  UI:   Shows new value in "Current: 45 minutes"

Step 4: Save Changes
  User: Clicks [💾] Save Settings button
  App:  Executes saveSystemConfiguration() method
  API:  Calls PUT /api/SystemConfiguration with updated config
  DB:   Updates SystemConfiguration table
  UI:   Shows success message: "System configuration saved successfully!"

Step 5: Close Panel
  User: Clicks [X] close button or Cancel
  App:  Executes toggleSystemSettings() method
  State: showSystemSettings = false
  UI:   Panel closes, returning to normal view

================================================================================
                          TROUBLESHOOTING GUIDE
================================================================================

Problem: Button still not visible after applying fix
Solution:
  1. Verify npm run build completed successfully
  2. Hard refresh browser (Ctrl+Shift+R)
  3. Clear browser cache
  4. Check if ng serve is running
  5. Restart ng serve

Problem: Panel doesn't open when button is clicked
Solution:
  1. Open browser console (F12)
  2. Check for JavaScript errors
  3. Verify systemConfig is loaded
  4. Check if toggleSystemSettings() is being called

Problem: API returns 401 Unauthorized
Solution:
  1. Verify user is logged in as Admin
  2. Check if token contains CompanyId claim
  3. Verify backend is running on port 5000
  4. Check authorization header format

Problem: Changes don't save
Solution:
  1. Check if user has Admin role
  2. Verify validation passes
  3. Check network tab for API response
  4. Verify database connection
