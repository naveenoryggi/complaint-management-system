PROBLEM
-------
- Events showing as "event unknown" in notification rules UI
- Templates showing as "template unknown" in notification rules UI
- Administrators unable to properly manage notification configurations

ROOT CAUSE
----------
- Backend EventTypesController returns direct array: [{...}, {...}]
- Backend TemplatesController returns direct array: [{...}, {...}]
- Frontend services expected wrapped response: {"data": [{...}]}
- Mismatch caused response.data to be undefined, returning empty arrays
- UI lookup functions returned "Unknown" when arrays were empty

SOLUTION
--------
Updated Angular services to handle BOTH response formats:
1. notification-rule.service.ts - getEventTypes() methods
2. template.service.ts - getTemplates() methods

Implementation uses Array.isArray() check:
- If response is array -> return directly
- If response is object with .data -> return response.data
- Backward compatible, forward compatible, robust
