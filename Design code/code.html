How Escalations Work

1. Monitoring

The system continuously monitors all open complaints against your active rules.

2. Condition Check

When a complaint matches a Trigger (e.g. time elapsed), the rule is flagged.

3. Automated Action

The defined action executes immediately, notifying stakeholders or reassigning tickets.
